# QuickSub

QuickSub is a Nigerian VTU platform for mobile data and other digital services.

## Supplier
Model Virtual App (Sabuss)

## Technology
- Frontend: HTML, CSS, JavaScript
- Hosting: Cloudflare Pages
- Backend: Cloudflare Pages Functions
- Database: Cloudflare D1

## Core Features
- Mobile data plans organised by network and plan category.
- Original supplier plan names and IDs.
- Separate supplier prices and customer selling prices.
- Customer registration and login.
- Customer wallets and transaction history.
- Secure supplier API integration.
- Transaction status monitoring.
- Admin dashboard for managing the platform.

## Security
- Never expose supplier API credentials in public files.
- Validate transactions before updating wallet balances.
- Prevent duplicate purchases and refunds.

## Development
QuickSub will be developed in stages. Sample data will be used until the real supplier integration is ready for testing.
